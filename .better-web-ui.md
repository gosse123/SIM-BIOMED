# Design Context — SIM-BIOMED

- **Audience** : personnel hospitalier (techniciens biomédicaux, personnel soignant, responsables, direction) — usage terrain, mobile, parfois hors ligne.
- **Cas d'usage** : signaler une panne rapidement, qualifier/diagnostiquer, suivre la maintenance, consulter des indicateurs. Priorité : vitesse de la tâche, lisibilité, accessibilité.
- **Ton/personnalité** : sobre, fiable, clinique — pas de déco superflue. Le système existant (React + Tailwind, tokens existants dans `tailwind.config.ts`, composants `src/components/ui/`) fait foi : on le conserve et on l'étend, pas de rebranding.
